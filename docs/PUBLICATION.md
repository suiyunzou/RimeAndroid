# 发布与隐私说明

## 哪些内容公开

本仓库公开 Android 源码、构建所需的默认资源、来源与许可文件、自制字体生成源码，以及经过检查的模拟器截图。`.gitignore` 首先限制可进入仓库的目录，再排除敏感文件类型。

本地工作目录中还有其他资料，但它们不属于本仓库的发布范围：

- 个人词库、系统拼音导出的个人数据和学习记录。
- 自定义短语、邮箱规则、手机设置、安装标识和设备序列号。
- 剪贴板、输入历史、手机备份和原始设备截图。
- 调试日志、验收记录、历史 ZIP/APK、参考视频和模型实验文件。
- `local.properties`、签名密钥、令牌和本机工具路径。

公开的原作者署名、项目链接及词典中的普通人名地名予以保留。它们与私人联系人和用户输入记录不同。

## 图片

`docs/images` 中三张 PNG 来自模拟器，已经逐张查看。只包含空输入框、测试文字“你好”或设置界面；未使用私人手机截图。保留原图，未用生成图片替代真实界面。

## 检查方式

`scripts/verify-publication.py` 读取 Git 暂存区的实际文件内容，检查允许目录、敏感文件名、本机绝对路径、常见密钥格式、超大文件和符号链接，并核对公开资源的已有来源校验值。提交邮箱使用 GitHub 的 `noreply` 地址。

文件内容或截图仍需人工复核。没有任何简单扫描能够证明所有内容都绝对不含隐私。本仓库首次发布的检查范围和结果见 [`VALIDATION.md`](VALIDATION.md)。

## 应用运行时数据

应用的剪贴板、个人词库等功能会在使用时产生本地数据。这些数据不应加入 Git。当前源码的 Android Manifest 明确移除联网权限；本次整理没有重新进行完整的运行时隐私审计，也不将此描述为对操作系统或第三方输入方案的保证。
