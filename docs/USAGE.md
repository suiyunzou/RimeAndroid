# 使用说明

## 第一次启动

1. 安装自己编译的 APK。
2. 按应用提示，在 Android 设置中启用“同文输入法”，并切换到它。
3. 完成输入法初始化和部署。部署是把方案文件转换为输入法可用的数据，第一次通常比后续启动慢。
4. 在输入方案中选择内置的“朙月拼音”或“朙月拼音·简化字”等可用方案。
5. 在主题设置中选择“ios风格”，即可使用 README 所示的参考主题；原主题标识与配色设置继续沿用。

菜单名称可能随 Android 系统不同而变化。官方同文输入法和本定制版可以共存；本版包名是 `local.trime.panels`。

## 常用操作

| 想做的事 | 操作 |
| --- | --- |
| 切换中英文 | 点键盘底部的地球键 |
| 查看后续候选词 | 在候选行左右滑动；向下滑动或点展开按钮查看更多 |
| 查看候选说明 | 长按候选词，查看词库说明或原拼音、纠错拼音；点击候选仍直接上屏 |
| 填入短信验证码 | 在“设置 → 输入 → 短信验证码”开启并允许短信权限；收到验证码后点键盘顶部“填入” |
| 输入数字的其他写法 | 打开数字页，长按数字，再选择候选；横滑查看后续选项 |
| 设置拨动输入 | 打开增强设置中的“按键”，选择方向，再点键盘预览中的按键 |
| 单次输入角标 | 按设定方向快速拨动字母；默认下拨 |
| 进入符号锁定 | 原地按住至少 350 毫秒，再按设定方向拨动；点 `ABC` 退出 |
| 编辑光标 | 原地长按字母至 800 毫秒出现放大镜，再拖动 |
| 使用空格轮盘 | 长按空格，向目标方向短移约 10dp 后松手；回中心可取消 |
| 输入农历 | 进入空格轮盘的时间项后继续上移，再左右滑动到“农历日期”或“农历时辰”，松手填入 |
| 计算器 | 数字和运算符实时进入宿主；右侧预览结果，点 `=` 追加结果 |
| 使用剪贴板分词 | 打开剪贴板面板，选择文字后使用分词或拆分功能 |

短信识别默认关闭，只处理开启后新收到的短信，不读取短信历史。验证码在本机内存保留最多 5 分钟，填入或关闭后清除；密码框不显示提示。填入操作不提交表单。系统若不允许短信权限，此功能不能开启，可继续手动输入。

农历按北京时间计算，显示干支年、农历月日、闰月和可选时辰，日期在午夜切换。需要 Android 7.0 或更高版本；较旧系统保留原来的公历时间选项。

## 内置与可选内容

基础输入可使用 APK 内的默认资源。完整万象或雾凇输入方案、邮箱后缀等仍需兼容的 Rime 配置。2.31 内置约 46.2 MiB 精简整句模型，可在“设置 → 输入 → 整句模型”安装、查看和切换；完整版约 398.7 MiB，可在该页面下载。词库页提供万象名人、艺人、多音字词下载和手动加词。仓库中的滑行词表仅服务于滑行候选，不能替代完整的 Rime 输入方案。

README 截图来自此前配置好的模拟器，用于说明界面。首次安装只包含公开默认资源，不会带入作者的个人设置。原版 Trime 的配置方法可参考 [Trime 文档](https://github.com/osfans/trime/wiki)。

## 反馈问题

说明 Android 版本、应用版本、输入方案和复现步骤即可。截图前清空输入框、候选中的个人词条和剪贴板。不要直接上传用户词库、配置备份、签名文件或完整手机日志。
