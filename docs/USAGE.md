# 使用说明

## 第一次启动

1. 安装自己编译的 APK。
2. 按应用提示，在 Android 设置中启用“同文输入法”，并切换到它。
3. 完成输入法初始化和部署。部署是把方案文件转换为输入法可用的数据，第一次通常比后续启动慢。
4. 在输入方案中选择内置的“朙月拼音”或“朙月拼音·简化字”等可用方案。
5. 在主题设置中选择“视频参考 · ReRime”，即可使用 README 所示的参考主题。

菜单名称可能随 Android 系统不同而变化。官方同文输入法和本定制版可以共存；本版包名是 `local.trime.panels`。

## 常用操作

| 想做的事 | 操作 |
| --- | --- |
| 切换中英文 | 点键盘底部的地球键 |
| 输入数字的其他写法 | 打开数字页，长按数字，再选择候选；横滑查看后续选项 |
| 设置拨动输入 | 打开增强设置中的“按键”，选择方向，再点键盘预览中的按键 |
| 退出符号锁定 | 点 `ABC` |
| 使用剪贴板分词 | 打开剪贴板面板，选择文字后使用分词或拆分功能 |

## 内置与可选内容

基础输入可使用 APK 内的默认资源。完整万象、雾凇、整句模型、邮箱后缀及个人短语需要你自行准备兼容的 Rime 配置。仓库中的滑行词表仅服务于滑行候选，不能替代完整的 Rime 输入方案。

README 截图来自此前配置好的模拟器，用于说明界面。首次安装只包含公开默认资源，不会带入作者的个人设置。原版 Trime 的配置方法可参考 [Trime 文档](https://github.com/osfans/trime/wiki)。
